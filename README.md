# augustodamasceno.org

Personal website and portfolio of Augusto Damasceno — https://augustodamasceno.org/

Static site built with Jekyll and served by GitHub Pages. Specs in [AGENTS.md](AGENTS.md).

## Run locally

```sh
jekyll serve --livereload
# http://127.0.0.1:4000/styleguide/
```
